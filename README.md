## Projetos

### lab-active-directory
Ambiente virtualizado com Windows Server 2022 e Windows 11 Pro. Active Directory com OUs, usuários, grupos e 4 GPOs de segurança aplicadas e validadas. 🔗 [github.com/MaykFarias/lab-active-directory](https://github.com/MaykFarias/lab-active-directory)

### powershell-ti
Script PowerShell de diagnóstico para Suporte TI — coleta RAM, processos, serviços críticos e testa conexão com a internet. 🔗 [github.com/MaykFarias/powershell-ti](https://github.com/MaykFarias/powershell-ti)

### linux-log-analyzer
Script Bash que analisa arquivos de log do sistema, categorizando entradas por nível de severidade (INFO, WARNING, ERROR) e exibindo contagem e listagem de cada ocorrência no terminal. 🔗 [github.com/MaykFarias/linux-log-analyzer](https://github.com/MaykFarias/linux-log-analyzer)

### redes-alura
Repositório com exercícios práticos do curso de Redes da Alura, utilizando Cisco Packet Tracer. Cobre desde conceitos iniciais até VLANs, roteamento, DNS, IPv6 e redes Wi-Fi. 🔗 [github.com/MaykFarias/redes-alura](https://github.com/MaykFarias/redes-alura)
